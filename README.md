# 合数流量运营支持系统｜视频管理 P0 交互原型

这是根据 OpenProject「视频管理原始需求」制作的独立可操作前端原型。它用于冻结 P0 业务闭环、页面结构、状态流转和权限行为，为后续迁入 `heshu-idms-web` 提供可验证基线。

## 范围边界

本目录只实现视频管理，不包含营销分析、资金监控、账户配置、企微群 Bot 或其他模块，也没有修改工作区中的企微工程。

当前版本是浏览器本地原型：

- 不连接生产数据库；
- 不上传或下载真实视频；
- 不调用抖音、小红书、快手或视频号 API；
- 不读取任何账号密码；
- 所有业务记录均明确标记为“演示数据”；
- 交互结果保存在当前浏览器的 `localStorage` 中，可通过侧栏“重置演示数据”恢复。

## 已实现功能

### 1. 我的工作台

- 编导、剪辑、投手、运营四种角色切换；
- 按角色计算待办、待审片、剪辑中、待发布和卡审数量；
- 优先任务可直接打开详情；
- `⌘ K` / `Ctrl K` 搜索任务、成片和功能入口。

### 2. 拍摄任务

- 新建选题时自动生成只读选题 ID；
- 选题脚本类型支持“主页脚本 / 投流脚本”；
- 业务线使用下拉多选，当前选项为“教育规划 / 大场 / 豆神双语”；
- 选题列表同步显示脚本类型和多个业务线；
- 新建拍摄任务；
- 选题、脚本、开头、拍摄日期、场地等基础信息；
- 任务进度和拍摄文档结构；
- 模拟原片批量上传与进度；
- 原片登记后进入“待分配剪辑”；
- 从脚本生成并分配剪辑任务；
- 打印专用样式，可通过浏览器打印为 PDF。

### 3. 剪辑任务与审片

- 优先级、负责人、截止日期和来源拍摄任务；
- 待剪辑、剪辑中、待审片、待修改、审片通过、卡审修改状态；
- 开始剪辑；
- 填写实际开头、实际标题和标准成片文件名；
- 提交新修订版；
- 编导审片通过或结构化退回修改；
- 修改意见、操作人和时间线留痕；
- 审片通过后自动创建视频成片。

### 4. 视频成片与平台审核

- 成片标题、标准文件名、时长、大小、剪辑负责人和通过时间；
- 从成片反查选题、拍摄任务、剪辑任务和引用原片；
- 手工登记平台、账户、素材 ID / 笔记 ID、发布时间和链接；
- 抖音、小红书、快手、视频号记录互相独立；
- 标记平台审核通过或卡审；
- 保存卡审原因；
- 从卡审记录重开剪辑任务；
- 重开后剪辑任务进入“卡审修改”，平台素材进入“待重新上传”。

### 5. 内容素材库

- 侧栏按“生产工作区 / 内容与资产”分组，保留原有页面和业务职责；
- 自动把现有成片、原片、拍摄脚本、标题和开头写入统一素材索引，不复制源文件；
- 按类型、流转状态、合规状态、关键词和素材集合组合筛选；
- 卡片视图与列表视图切换；
- `待整理 → 可复用 → 使用中 → 受限 / 已归档`素材流转；
- 流转状态、合规状态、表现标签三个维度独立维护；
- 素材标签编辑；
- 新建素材集合、添加或移除集合关系；
- 人工登记外部素材，默认进入“待整理”和“未复核”；
- 素材详情展示来源对象、使用记录、所属集合和素材血缘；
- 从成片、原片、脚本、标题或开头直接创建重剪任务；
- 重剪任务保存来源素材 ID，后续剪辑和成片可继续反查。

### 6. 基础资产列表

- 选题脚本列表和搜索；
- 视频原片列表和搜索；
- 按文件名、场景、机位、镜号、选题和 IP 查找；
- 原片到成片的引用数量。

## 本地运行

该原型没有构建依赖。在本目录启动任意静态文件服务即可：

```bash
python3 -m http.server 4181
```

然后访问：

```text
http://127.0.0.1:4181
```

也可以直接打开 `index.html`，但使用本地 HTTP 服务更接近实际 Web 运行环境。

## 角色权限

| 动作 | 编导 | 剪辑 | 投手 | 运营 |
|---|---:|---:|---:|---:|
| 新建拍摄任务 / 选题 | 是 | 否 | 否 | 否 |
| 上传原片 | 是 | 是 | 否 | 否 |
| 分配剪辑 | 是 | 否 | 否 | 否 |
| 开始剪辑 / 提交审片 | 否 | 是 | 否 | 否 |
| 审片通过 / 退回修改 | 是 | 否 | 否 | 否 |
| 登记发布 / 平台审核 | 否 | 否 | 是 | 是 |
| 因卡审重开剪辑 | 是 | 否 | 是 | 是 |
| 新建集合 / 整理素材 | 是 | 否 | 是 | 是 |
| 从素材创建重剪任务 | 是 | 否 | 是 | 是 |
| 更新素材流转与合规 | 是 | 否 | 是 | 是 |

这是前端原型权限，用于展示期望行为。生产环境必须由服务端再次校验，不能只依赖按钮禁用。

## 生产接入前提

1. 提供正确源码仓库：`heshu-idms-web`、`heshu-idms-service` 和相关数据服务；
2. 明确对象存储资产，优先采用浏览器分片直传 OSS / S3，不能把大文件长期放在 ECS 系统盘；
3. 明确上传凭证、回调登记、转码、封面和预览代理文件能力；
4. 明确现有用户、组织、角色和数据权限接口；
5. 平台上传与审核 API 可后接，不能阻塞 P0 的人工发布登记；
6. 服务端分别维护拍摄任务、剪辑任务和平台素材三个状态机；
7. 文件名只用于识别，数据库关系必须使用不可变资产 ID。
