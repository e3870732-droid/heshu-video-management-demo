# 合数流量运营支持系统｜视频管理 P0 交互原型

这是根据 OpenProject「视频管理原始需求」制作的独立可操作前端原型。它用于冻结 P0 业务闭环、页面结构、状态流转和权限行为，为后续迁入 `heshu-idms-web` 提供可验证基线。

## 范围边界

本目录只实现视频管理，不包含营销分析、资金监控、账户配置、企微群 Bot 或其他模块，也没有修改工作区中的企微工程。

当前版本是浏览器本地原型：

- 不连接生产数据库；
- 不上传或下载真实视频；
- 不调用抖音、小红书、快手或视频号 API；
- 不读取任何账号密码；
- 所有业务记录均明确标记为“演示数据”；
- 交互结果保存在当前浏览器的 `localStorage` 中，可通过侧栏“重置演示数据”恢复。

## 已实现功能

### 1. 我的工作台

- 编导、剪辑、投手、运营、数据分析师五种角色切换；
- 数据分析师全量数据只读，可写评论与内容分析，但不介入编导、剪辑、投手、运营的工作流；
- 编导工作台覆盖五类待办：待审片 / 待处理卡审 / 待分配剪辑 / 待补拍摄信息 / 待上传原片；
- 按角色计算待办、待审片、剪辑中、待发布和卡审数量；
- 优先任务可直接打开详情；
- `⌘ K` / `Ctrl K` 搜索任务、成片和功能入口。

### 2. 拍摄任务

- 新建选题时自动生成只读选题 ID；
- 选题脚本类型支持“主页脚本 / 投流脚本”；
- 业务线使用下拉多选，当前选项为“教育规划 / 大场 / 豆神双语”；
- 选题列表同步显示脚本类型和多个业务线；
- 新建拍摄任务；
- 选题、脚本、开头、拍摄日期、场地等基础信息；
- 脚本支持随时追加与编辑（标题 / 开头 / 剪辑须知）；
- 拍摄后补录命名信息（场景 / IP / 服装 / 设备 / 机位），任务进入“已拍摄待补录”；
- 任务进度和拍摄文档结构；
- 模拟原片批量上传与进度；
- 原片登记后进入“待分配剪辑”；
- 从脚本生成并分配剪辑任务；
- 打印专用样式，可通过浏览器打印为 PDF。

### 3. 剪辑任务与审片

- 优先级、负责人、截止日期和来源拍摄任务；
- 待剪辑、剪辑中、待审片、待修改、审片通过、卡审修改状态；
- 开始剪辑；
- 填写实际开头、实际标题和标准成片文件名；
- 提交新修订版；
- 编导审片通过或结构化退回修改；
- 修改意见、操作人和时间线留痕；
- 审片通过后自动创建视频成片。

### 4. 视频成片与平台审核

- 成片标题、标准文件名、时长、大小、剪辑负责人和通过时间；
- 从成片反查选题、拍摄任务、剪辑任务和引用原片；
- 手工登记平台、账户、素材 ID / 笔记 ID、发布时间和链接；
- 抖音、小红书、快手、视频号记录互相独立；
- 标记平台审核通过或卡审；
- 卡审登记包含原因分类、原因原文与卡审截图（截图为占位登记，生产环境上传对象存储后回填链接）；
- 从卡审记录重开剪辑任务；
- 卡审记录可判定为废片：平台素材失效、不再占用剪辑资源，全部平台记录判废时成片素材自动归档停用；
- 失效平台记录不参与成片“总体发布状态”计算（仅统计有效记录）；
- 重开后剪辑任务进入“卡审修改”，平台素材进入“待重新上传”。

### 5. 内容资产

- 侧栏按原始系统信息架构组织：工作台 / 内容资产（素材库、成片、外部素材）/ 剪辑中心（选题脚本=选题脚本库、拍摄任务、剪辑任务、视频成片），实时监控、数据洞察、配置管理保留入口但标记"未纳入 P0"；
- 内容资产 > 素材库合并原"脚本"与"原片"两个入口，只做素材管理、不含剪辑分析：脚本以 PDF 文档形式管理，点击卡片即打开 PDF 预览抽屉（标题 / 开头 / 剪辑须知分页展示，可直接下载）；原片视频按设备编号组织（相机 CAM-01/02、手机 PHONE-01/02），每个编号下含正面 / 侧面与不同服装的多条视频，卡片标注设备编号、角度与服装；
- 素材库顶部为合集胶囊筛选条（全部素材 + 各合集），新建合集按钮在搜索行右侧；筛选支持关键词、IP 老师、设备编号与类型页签（全部 / 脚本 PDF / 原片视频）；一键下载按当前筛选导出脚本 Markdown；
- 自动把现有成片、原片、拍摄脚本、标题和开头写入统一素材索引，不复制源文件；
- 按类型、流转状态、合规状态、关键词和素材集合组合筛选；
- 卡片视图与列表视图切换；
- `待整理 → 可复用 → 使用中 → 受限 / 已归档`素材流转；
- 流转状态、合规状态、表现标签三个维度独立维护；
- 素材标签编辑；
- 新建素材集合、添加或移除集合关系；
- 人工登记外部素材，默认进入“待整理”和“未复核”；
- 素材详情展示来源对象、使用记录、所属集合和素材血缘；
- 从成片、原片、脚本、标题或开头直接创建重剪任务；
- 重剪任务保存来源素材 ID，后续剪辑和成片可继续反查。

### 6. 选题脚本库（选题复盘）

- 列表层对齐「素材增长中心 · 选题与脚本」参考页：选题/脚本摘要、视频用途、已拍版本、历史表现 ROI 四列；
- 右侧选题标签面板（标签计数、点击筛选）与选题表现面板（高潜选题 / 待补拍 / 衰退选题，演示口径）；
- 支持导入选题（批量粘贴，每行一个）与新建选题（可维护选题标签）；
- 选题列表按千川累计预估利润从高到低排序（演示数据，接入千川 API 后替换）；
- 按选题名称 / 拍摄版本 / 拍摄日期 / 产品·项目 / IP / 关键词组合查询；
- 选题详情包含：选题累计数据、代表视频（累计利润 Top 5 剪辑版本）、选题评论、拍摄版本列表；
- 一次拍摄任务可包含多个拍摄版本，版本名称系统自动生成、可修改；
- 拍摄版本支持人工 S / A 定级（编导、数据分析师），选题详情默认展开 S / A 级版本，其余历史版本手动加载；
- 拍摄版本包含：版本累计数据、拍摄脚本、脚本内容分析（自由文本，不限结构）、对应成片、拍摄脚本评论；
- 选题评论与拍摄脚本评论支持所有角色发表、编辑和删除，评论仅留痕、不驱动状态流转；
- 视频原片列表和搜索；
- 按文件名、场景、机位、镜号、选题和 IP 查找；
- 原片到成片的引用数量。

## 本地运行

该原型没有构建依赖。在本目录启动任意静态文件服务即可：

```bash
python3 -m http.server 4181
```

然后访问：

```text
http://127.0.0.1:4181
```

也可以直接打开 `index.html`，但使用本地 HTTP 服务更接近实际 Web 运行环境。

## 生产接入前提

1. 提供正确源码仓库：`heshu-idms-web`、`heshu-idms-service` 和相关数据服务；
2. 明确对象存储资产，优先采用浏览器分片直传 OSS / S3，不能把大文件长期放在 ECS 系统盘；
3. 明确上传凭证、回调登记、转码、封面和预览代理文件能力；
4. 明确现有用户、组织、角色和数据权限接口；
5. 平台上传与审核 API 可后接，不能阻塞 P0 的人工发布登记；
6. 服务端分别维护拍摄任务、剪辑任务和平台素材三个状态机；
7. 文件名只用于识别，数据库关系必须使用不可变资产 ID。
